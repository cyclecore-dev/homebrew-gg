# Homebrew Tap for gg

Official Homebrew tap for [gg](https://github.com/cyclecore-dev/gg) — the 2-letter agent-native git client.

## Install

```bash
brew tap cyclecore-dev/gg
brew install gg
```

Or directly:

```bash
brew install cyclecore-dev/gg/gg
```

## Update

```bash
brew upgrade gg
```

## Uninstall

```bash
brew uninstall gg
brew untap cyclecore-dev/gg
```

## About gg

gg provides 98% token savings for AI agents on git/npm/brew operations.

- `gg .` — Current repo → MCP (~12 tokens)
- `gg npm prettier` — npm package info (~18 tokens)
- `gg brew ffmpeg` — Homebrew formula (~22 tokens)
- `gg ask "prompt"` — AI code generation

Learn more: https://github.com/cyclecore-dev/gg
